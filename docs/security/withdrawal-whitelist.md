# Withdrawal Address Whitelist

The whitelist restricts withdrawals to pre-approved addresses only. This prevents unauthorized withdrawals even if your account credentials are compromised.

---

## Adding an address

1. Go to **Settings → Security → Withdrawal Whitelist**
2. Click **Add Address**
3. Enter:
   - **Address** — the destination wallet address
   - **Network** — the blockchain network (must match the address format)
   - **Label** — a friendly name (e.g., "My Ledger ETH", "Cold Wallet BTC")
4. Verify via email link
5. Confirm with your 2FA code
6. **The address becomes active after 24 hours**

---

## The 24-hour delay

New addresses cannot be used for 24 hours after adding. This is intentional — it gives you time to detect unauthorized additions and contact support before a withdrawal is possible.

You will receive an email notification when a new address is added. If you did not initiate this, contact support immediately.

---

## Managing addresses

Go to **Settings → Security → Withdrawal Whitelist** to:
- View all whitelisted addresses
- Remove an address (takes effect immediately for future withdrawals)
- Rename labels

---

## Best practices

- Add your personal wallet addresses well before you plan to withdraw
- Use a hardware wallet address as your primary withdrawal destination
- Remove addresses you no longer use
- Review the list periodically for unauthorized additions
