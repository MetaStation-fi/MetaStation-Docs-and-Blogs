# Session Management

View and manage all active sessions on your MetaStation account.

---

## Viewing active sessions

Go to **Settings → Security → Sessions** to see:
- Device type and browser
- IP address and approximate location
- Last active time
- Current session (marked)

---

## Revoking a session

If you see an unrecognized device or location:

1. Click **Revoke** next to the session
2. That device is immediately logged out

To log out of all sessions at once, click **Revoke All Other Sessions**.

---

## Session timeout

Sessions expire automatically after a period of inactivity. You can configure the timeout duration in **Settings → Security → Session Timeout**.

---

## What to do if your account is compromised

1. **Change your password immediately** — Settings → Security → Change Password
2. **Revoke all sessions** — this logs out all devices
3. **Review withdrawal history** — confirm no unauthorized withdrawals occurred
4. **Check withdrawal whitelist** — remove any addresses you did not add
5. **Contact support** — report the incident for investigation
6. **Re-enable or reconfigure 2FA** if it was bypassed
