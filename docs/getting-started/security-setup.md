# Security Setup

Set up these security features before trading. They protect your account and are required for withdrawals.

---

## Two-Factor Authentication (2FA)

2FA adds a second verification step to login and all withdrawals.

**Setup:**

1. Go to **Settings → Security → Two-Factor Authentication**
2. Scan the QR code with your authenticator app (Google Authenticator, Authy, or any TOTP app)
3. Enter the 6-digit code to confirm
4. Save your backup codes in a secure location — these are your recovery option if you lose your phone

:::warning
**Never share your 2FA codes or backup codes with anyone.** MetaStation support will never ask for them.
:::

---

## Withdrawal Address Whitelist

Whitelisting restricts withdrawals to pre-approved addresses only.

1. Go to **Settings → Security → Withdrawal Whitelist**
2. Click **Add Address**
3. Enter the wallet address and label it
4. Confirm via email and 2FA
5. There is a 24-hour waiting period before a new address becomes active

Only whitelisted addresses can receive withdrawals from your account.

---

## Strong password

- Minimum 8 characters
- Use a mix of uppercase, lowercase, numbers, and symbols
- Never reuse a password from another service
- Use a password manager

---

## Session management

View and revoke active sessions at **Settings → Security → Sessions**. If you see an unrecognized device, revoke it immediately and change your password.
