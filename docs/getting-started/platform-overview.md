# Platform Overview

A tour of the MetaStation interface.

---

## Dashboard

The dashboard shows your portfolio at a glance:

- **Total portfolio value** across all connected accounts
- **Open positions** and unrealized P&L
- **Recent trade history**
- **Balance breakdown** per account slot

---

## Account Slots

Account slots are the core unit of MetaStation. Each slot represents one trading account.

| Slot Type | How to get it | What's included free |
|---|---|---|
| MetaStation Account | Created automatically at registration | All automation tools (webhooks, Telegram-to-Trade, copy trading, advanced orders) |
| Binance | Connect your Binance API keys | Manual trading only |
| ByBit | Connect your ByBit API keys | Manual trading only |
| KuCoin | Connect your KuCoin API keys | Manual trading only |

To unlock **automation tools** (webhooks, Telegram-to-Trade) on a Binance, ByBit, or KuCoin slot, purchase an **account slot subscription** from the Store.

→ [Account Slots reference](/docs/trading/account-slots)

---

## Trading Terminal

The trading terminal has:

- **TradingView chart** with full indicator and drawing tool support
- **Order book** with real-time depth
- **Order entry panel** — market, limit, stop orders with TP/SL
- **Open positions** panel with live P&L
- **Trade history** and order history

Switch between account slots using the slot selector at the top of the trading terminal.

---

## Navigation

| Section | Purpose |
|---|---|
| **Trade** | Trading terminal for your selected account slot |
| **Portfolio** | All positions, balances, and P&L across accounts |
| **Marketplace** | Browse and subscribe to signal providers |
| **Wallet** | Deposit, withdraw, and manage assets |
| **Store** | Purchase account slot subscriptions |
| **Settings** | Account, security, API keys, notification preferences |
