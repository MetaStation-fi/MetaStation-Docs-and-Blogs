Execute trades on one of your MetaStation account slots via HTTP POST webhooks.
Signals can be sent in JSON or natural language format.

Every slot has its own webhook URL. Its verification mode (Automation page)
decides what else a request must carry: nothing (URL only), an
X-MetaStation-Signature header (Signed requests), or a TradingView source
address (Source-address check).
