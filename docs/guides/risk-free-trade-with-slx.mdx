# Make a Trade Risk-Free with SLX

**The job:** a trade goes your way, hits the first target — and can no longer lose money. No
watching, no manual stop adjustment.

**You need:** any MetaStation slot, and a position with at least one take-profit level.

---

## The problem it solves

A position with a fixed stop and a take-profit ladder can still hit TP1, reverse, and stop out at
a loss on everything remaining. You were right about direction, got paid on 30% of the position,
and lost anyway.

The manual fix is to move the stop to entry after TP1 fills. That works if you are watching. It
does not work at 4am, which is when it matters.

**SLX (Stop Loss X)** does it automatically, and it is what distinguishes it from a plain trailing
stop: a trailing stop follows *price*, SLX follows *your take-profit events*.

---

## Mode 1 — Breakeven at TP1

The simplest and the most useful. Once your chosen level fills, the stop moves to entry.

```json
{
  "stopLossX": {
    "slxMode": "trailing_profits",
    "activationPoint": "TP1",
    "trailingType": "breakeven"
  }
}
```

Long from $45,000 with TP1 at $48,000:

1. Price reaches $48,000 → TP1 fills, closing its slice.
2. SLX moves the stop from $41,000 to **$45,000**.
3. The remaining position cannot lose money. TP2 and TP3 stay open.

The trade is now free to run.

## Mode 2 — Walk the stop up the ladder

`follow_tp` moves the stop to the *previous* level each time a new one fills, locking in each
completed rung.

```json
{
  "stopLossX": {
    "slxMode": "trailing_profits",
    "activationPoint": "TP1",
    "trailingType": "follow_tp"
  }
}
```

With TPs at $48,000 / $50,000 / $52,000:

| Event | Stop moves to |
|---|---|
| TP1 fills | $45,000 (entry) |
| TP2 fills | $48,000 (TP1) |
| TP3 fills | $50,000 (TP2) |

Each completed step is banked. The cost is that a normal pullback after TP2 now closes you at
TP1's price rather than letting the position breathe — this mode suits trends, not chop.

## Mode 3 — Callback rate

Percentage trailing from the peak, activated at a price rather than at a TP event. Use it when
the position has no ladder to key off.

```json
{
  "stopLossX": {
    "slxMode": "callback_rate",
    "activationPrice": 46000,
    "callbackRate": 2.0,
    "triggerBy": "mark_price"
  }
}
```

Trailing starts at $46,000 and the stop sits 2% below the highest price seen since. Peak $50,000
→ stop $49,000. The stop ratchets up and never moves down.

Keep `triggerBy` on `mark_price` unless you have a specific reason not to — `last_price` reacts to
every print, including the single-wick outliers a smoothed price exists to ignore.

## Configuring it in the UI

1. Open **Advanced Orders** in the order panel.
2. Toggle **Stop Loss X**.
3. Choose **Callback Rate** or **Trailing Profits**.
4. Fill in the parameters and confirm.

## The complete automated entry

Everything together — entry, ladder, stop, and SLX — in one payload:

```json
{
  "action": "open",
  "symbol": "BTCUSDC",
  "side": "buy",
  "orderType": "market",
  "quantity": "3%",
  "leverage": 5,
  "marginMode": "isolated",
  "takeProfits": [
    { "price": 48000, "quantity": "30%" },
    { "price": 50000, "quantity": "40%" },
    { "price": 52000, "quantity": "remainder" }
  ],
  "stopLoss": 41000,
  "stopLossX": {
    "slxMode": "trailing_profits",
    "activationPoint": "TP1",
    "trailingType": "breakeven"
  }
}
```

This is the payload most automated strategies should be sending. It defines the entry, the exits,
the worst case, and the point at which the worst case becomes zero — all before the position
exists.

---

## Choosing a mode

| Situation | Mode |
|---|---|
| You want the trade safe as soon as possible | `trailing_profits` + `breakeven` |
| Strong trend, you want to ride and bank each step | `trailing_profits` + `follow_tp` |
| No take-profit ladder on the position | `callback_rate` |
| Choppy market | `breakeven` — `follow_tp` will stop you out on noise |

:::caution Breakeven is not free
Moving the stop to entry means an ordinary pullback can close the position for zero on a trade
that would have worked. You are trading some win rate for a much shorter tail of losses. That is
usually the right trade, but it is a trade.
:::
