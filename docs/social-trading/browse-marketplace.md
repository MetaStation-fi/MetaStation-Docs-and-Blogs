# Browse the Marketplace

The marketplace lists all active signal providers on MetaStation. Browse, filter, and evaluate traders before subscribing.

---

## Accessing the marketplace

Go to the **Marketplace** tab in the main navigation. All active providers are listed with their performance metrics.

---

## Filtering and sorting

| Filter | Options |
|---|---|
| ROI | Sort by highest return |
| Win Rate | % of profitable trades |
| Max Drawdown | Largest loss period — lower is safer |
| Total Trades | Volume of experience |
| Followers | Number of active subscribers |
| Subscription Price | Monthly cost |
| Asset Focus | BTC-only, altcoins, diversified |

---

## Reading a provider profile

Click any provider to view their full profile:

**Performance metrics:**
- **ROI** — Total return since launch
- **Win Rate** — Percentage of winning trades
- **Max Drawdown** — Largest peak-to-trough loss (lower = more controlled risk)
- **Avg Trade Duration** — Scalper (minutes) vs swing trader (days)
- **Sharpe Ratio** — Risk-adjusted return
- **Total Trades** — More trades = more data to evaluate
- **Active Followers** — How many users are currently copying

**Strategy description** — Written by the provider. Look for clear strategy logic, not vague promises.

**Trade history** — Individual trades, entry/exit, result. Verify the ROI is real, not from a single lucky trade.

---

## Red flags

:::warning
Watch for these signs of unreliable providers:
- ROI based on 1–3 trades only
- Monthly ROI above 100% with no drawdown
- No strategy description or vague language ("I trade with feelings")
- Sudden spike in ROI followed by inactivity
:::

---

## Green signals

- Consistent returns over 3+ months
- Win rate between 50–70% (100% win rate is unsustainable)
- Max drawdown under 30%
- Active, frequent posting and communication
