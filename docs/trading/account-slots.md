# Account Slots

Account slots are the unit of account management in MetaStation. Each slot is an independent trading configuration with its own balance, settings, and automation rules.

---

## Slot types

| Slot | Source | Default | Automation |
|---|---|---|---|
| MetaStation Account | Native — created at registration | First slot: free with all automation | Additional slots: paid from Store |
| Binance | Your own Binance API keys | 1 free manual slot | Automation: paid from Store |
| ByBit | Your own ByBit API keys | 1 free manual slot | Automation: paid from Store |
| KuCoin | Your own KuCoin API keys | 1 free manual slot | Automation: paid from Store |

---

## What "manual" means

A free manual slot on Binance, ByBit, or KuCoin lets you:
- Trade from the MetaStation terminal
- Follow marketplace signal providers (copy trading as a follower)
- View positions and history

A manual slot **does not** include:
- Webhook automation
- Telegram-to-Trade
- Advanced automated order routing

---

## Unlocking automation

Purchase an **account slot subscription** from the **Store** to unlock automation tools on any Binance, ByBit, or KuCoin slot.

**Automation tools unlocked:**
- Webhook integration
- Telegram-to-Trade
- Advanced automated order routing
- Priority support

**Billing terms:** Monthly, Quarterly, or Annual. Longer terms are discounted.

---

## MetaStation Account slots

Your first MetaStation Account slot is automatically created and includes all automation tools free. Additional MetaStation Account slots (for separate strategies) are available from the Store.

---

## Managing slots

Go to **Settings → Account Slots** to:
- View all connected slots
- Add a new exchange slot
- Configure settings per slot (webhook, social trade, leverage defaults)
- Manage subscriptions and billing

---

## Auto-renewal

Paid subscriptions auto-renew at the end of each billing period. Renewal notifications are sent by email. A grace period applies on payment failure.
